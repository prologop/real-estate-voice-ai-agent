# Real Estate Voice AI Agent 📞🤖

An AI-powered voice agent built for real estate lead handling and initial customer conversations.

### What it does

* Handles inbound/outbound real estate conversations
* Understands customer queries and responds naturally
* Collects basic lead information
* Helps qualify potential leads
* Automates the initial stage of the sales process

### Tech Stack

* Vapi
* AI / LLM
* Voice AI
* APIs & Webhooks

Project Goal

Built to explore how AI voice agents can automate repetitive customer interactions and improve lead-handling workflows.
